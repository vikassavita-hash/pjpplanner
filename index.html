📋 Step-by-Step Setup Guide

1. Create a Google Spreadsheet: Create a blank Google Sheet. Add 3 tabs (sheets) with these exact names:
  • Store Master
  • User Master
  • PJP Schedule
2. Open Apps Script: In your Google Spreadsheet, click Extensions > Apps Script.
3. Paste Code: Delete any code inside the editor and paste the template script shown below. Save the project.
4. Deploy as Web App: Click Deploy > New deployment.
  • Select type: Web app
  • Execute as: Me (your-email)
  • Who has access: Anyone
⚠️ CRITICAL: You MUST select "Anyone" for access. If left as "Only myself" or "Anyone with Google account", connection will fail with a CORS error because Google redirects the API request to the accounts sign-in screen.
Click Deploy, authorize permissions, and copy the generated Web app URL.
5. Connect: Paste the Web App URL and Token (`admin123` by default) into the settings panel on the left, then click Test Connection.
